# ICNS website review and redesign concepts

Deliverables from the review of https://www.westernsydney.edu.au/icns (24 Aug 2026),
built on the WSU 2026 brand guidelines and the ICNS design system.

- `icns-site-audit.html` — full-crawl audit (~100 pages): verified broken links,
  staleness findings, IA problems, accessibility debt, and a phased fix plan.
  Published: https://claude.ai/code/artifact/13ce11f8-8647-4680-83f3-88289bb3a328
- `icns-homepage-concept.html` — full homepage prototype in the dark "Plate"
  direction: static hero with live event-camera canvas, Dynamic Shift headline,
  masking shield, metadata-driven card system.
  Published: https://claude.ai/code/artifact/ad1a723b-1c56-4db6-b1cc-79fef5b1ce0f
- `icns-direction-board.html` — four hero-scale design directions
  (Plate / Paper / Charge / Journal) with rationale and token chips.
  Published: https://claude.ai/code/artifact/35ab9f85-ec4f-4206-81d5-25bcf1cca68e

All pages are self-contained static HTML (Open Sans from Google Fonts; canvases
respect prefers-reduced-motion). Production lockups must use supplied WSU logo
files, never redrawn type.

cognitive maps · an explainer

How do you
see the world?

Not the best method for building a world model — but how you, the one carrying a cognitive map around in your head, build a world at all. A robot can borrow the trick.

↓ scroll · two ideas, no maths degree required
01 · you already do this

Close your eyes. Where's your mug?

You didn't store a photograph of your desk. You stored a relation: mug, near the keyboard, left of the lamp. That's a cognitive map — what you encountered, bound to where you encountered it, all in one memory you can query from any angle. The rest of this page shows the same trick written as arithmetic a robot can run.

02 · the recipe · one object at a time

Build the map from what + where.

Every object you see becomes one vector: bind what it is to where it is, then add it to a single running pile.

Add every pair into M — one fixed-size vector that holds the whole room, however many objects you add.
No training, no growing memory. M is the same width after 3 objects or 30 — and you read it back by running the recipe in reverse.

Each dimension multiplies: phases add. The result encodes both mug and location — neither is readable alone without the other key.

mug_v ⊗ S(x,y) → bound pair
bundle · accumulate all items
⊕

Superposition.

M is the same size as any single bound pair. The dimension is fixed; only the density of information grows.

M = Σ aᵢ ⊗ S(xᵢ,yᵢ)
search · complex conjugate
⊗ v*

Phases subtract. The key cancels itself.

(φ+ψ) + (−φ) = ψ   the key's phase cancels

The conjugate flips the phase sign. Binding the target by its conjugate subtracts its angle exactly — leaving only the other factor. Everything else in M averages out to noise.

M ⊗ mug_v* ≈ S(x,y) + noise
Ask "where's the mug?": M ⊗ mug_v* → the answer peaks at its location. Ask "what's over there?": swap the key. One memory, queried from any angle — just like yours.

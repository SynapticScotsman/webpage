§01 SENSE · EVENT VISION

A frame camera samples thirty times a second.
An event sensor samples a million.

Biological retinas don't take snapshots — they fire spikes when something changes. By treating the world as a stream of asynchronous events, an agent spends its watts only when reality moves.

§02 BIND · COGNITIVE MAPS

The world isn't stored as pixels. It's stored as relations.

A cognitive map is the brain's trick for navigating a world it has never fully seen — holding what you encountered, where you encountered it, and how the pieces relate, all in one substrate you can query from any angle. We borrow that trick. Hyperdimensional vectors let us bind an object to a place with a single multiplication, bundle many such bindings into one trace, and pull any piece back out by unbinding. No floor plan. No SLAM mesh. Just a vector that remembers.

    DEMO 02-C · UNDER THE MATHS — THE POSITION CODE

    Spin the dials. The blob is the memory.

    S(x,y) = Bxx/ℓ ⊗ Byy/ℓ = 𝓕⁻¹{ eiA·(x,y)/ℓ }
    x position0.00 m
    y position0.00 m
    similarity
    0 → 1

    What you're seeing. The bright blob is similarity — the mean of cos(phase difference) across all dimensions. It falls to half height by ≈0.3ℓ, which is why every recall on this page answers with a blob, not a lit pixel. And because S(a) ⊗ S(b) = S(a+b) exactly, moving a whole memory is a single elementwise multiply.

    DEMO 03-B · WHY THE BRAIN APPEARS

    Grid cells fall out of the maths.

    grid modules combined1 module

    Build the position code from three plane waves at 120° — as HexagonalSSPSpace does — and one module's similarity map is an entorhinal grid cell. Stack scales and the lattices agree at exactly one place: a place cell. The path integrator in the spiking model is built from these.

    §04 REFLECT · UNCERTAINTY + ARCHIVE

    A good agent knows when it doesn't know.

    Uncertainty is treated as a first-class signal. When it crosses a threshold, the agent stops watching and starts probing — switching to active perception, asking the world questions until ambiguity collapses.

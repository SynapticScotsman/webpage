§01 SENSE · EVENT VISION

A frame camera samples thirty times a second.
An event sensor samples a million.

Biological retinas don't take snapshots — they fire spikes when something changes. By treating the world as a stream of asynchronous events, an agent spends its watts only when reality moves.

§02 BIND · COGNITIVE MAPS

The world isn't stored as pixels. It's stored as relations.

A cognitive map is the brain's trick for navigating a world it has never fully seen — holding what you encountered, where you encountered it, and how the pieces relate, all in one substrate you can query from any angle. We borrow that trick. Hyperdimensional vectors let us bind an object to a place with a single multiplication, bundle many such bindings into one trace, and pull any piece back out by unbinding. No floor plan. No SLAM mesh. Just a vector that remembers.

    §04 REFLECT · UNCERTAINTY + ARCHIVE

    A good agent knows when it doesn't know.
